# 识渔计划 · 项目交接说明

> 反钓鱼攻防训练 H5 游戏 ｜ 长春理工大学 · 计算机科学技术学院（参赛作品）
> 本文件是交接总入口：拿到包先读这里。

## 一、这是什么

一个纯前端 H5 游戏（零后端、零外部依赖、离线可运行），训练大学生识别钓鱼诈骗的能力：

| 模式 | 玩法 | 训练目标 |
|---|---|---|
| **账号体系** | 登录 / 注册（用户名+密码，无需邮箱手机）；训练数据按账号隔离；管理员角色多一个数据观测台 | 支撑班级演练与数据留存 |
| **拦截战** | 消息卡限时涌入，拖进左侧渔网（钓鱼）或右侧收件箱（正常）；连击计分、数据完整度血条、超时漏网 | 快速真假判断（行为训练） |
| **拆解台** | 把拦截下的证物（域名/链接/话术/附件碎片）拖进 7 类破绽槽位；首放命中计分、放错弹回 | 破绽定位与归类（知识内化） |
| **造浪者·组装实验室** | 拖基因卡入装配槽 + 三根滑杆调参（伪装度/激进度/投放量），预测仪带 ±8 误差，投放后邮件飞越扫描光束揭晓真实检出率；或**自由撰写**一封钓鱼邮件由规则引擎逐词高亮判检 | 攻击者视角反推防守 |
| **AI 蓝军安全官** | 全程打字机点评 + 浏览器语音播报 + 快捷追问 | 反馈与陪伴感 |
| **风险画像** | 前测→训练→后测，五维雷达图（域名甄别/话术免疫/链接警惕/附件谨慎/紧迫感抗压）+ 段位 + 个性化建议 | 效果量化（可写进论文/报告） |
| **AI 训练诊断** | 报告页/画像页：把段位、五维原始计数、漏判分布、错题本交给大模型，流式出具「总评/薄弱分析/训练处方」；带“AI 生成”来源标识，断网自动降级规则版建议 | 个性化反馈（云端→本地三层兜底） |
| **数据观测台（管理员）** | 6 个 KPI + 训练成效折线图（前测→后测）+ 破绽漏判环形图；题库编辑（校验靶点后即时生效）、4 波编排、账号管理（新增/改密/删除）、JSON 与 CSV 导出导入 | 班级演练观测与题库维护 |

## 二、怎么跑起来

1. **最快**：双击 `启动识渔计划.bat`（Windows，自动起本地服务并打开浏览器）。它把服务目录指向 `webapp/`——**不要把服务指向项目根目录**，否则会暴露目录列表与 `config.js`。
2. **通用**：任意静态服务器指向 `webapp/` 目录，如 `python -m http.server 8765`，访问 `http://127.0.0.1:8765`。
3. **上线部署**：`webapp/` 整目录上传静态托管即可（建议 HTTPS）；无构建步骤、无环境要求。
4. **登录**：打开先注册（用户名+密码，≥6 位）或用管理员账号登录，见根目录 `管理员账号.md`。

> 注意：不要用 `file://` 直接双击 index.html（部分浏览器限制 localStorage/语音），走本地服务器即可。

## 四、代码导读（5 分钟上手）

- 入口 `index.html` → `app.js` 底部 `init()`；视图切换 `show()`。
- **数据与逻辑完全分离**：加题/改题只动 `data.js`，不碰逻辑；样本 Schema 与扩展方法见 `webapp/README.md`。
- 交互核心都是**指针事件拖拽**（拦截卡/证物/基因卡三套 bind 函数），命中判定用"指针坐标落在槽内"（`slotAtPoint`），新增拖拽物复用该模式即可。
- 音效 `SFX`（WebAudio 合成）、语音 `Officer.tts`（Web Speech）——全部本地能力，无任何 API Key。

## 五、后端化路线（如需升级）

当前为"演示最优"的纯前端形态；`识渔计划_开发文档.md` §7 给出完整后端化设计（FastAPI + SQLite + LLM 生成管线 + 分类器判分），前端已预留三个替换点：
1. `Officer.play(script)` / `OFFICER_QA` → 换后端大模型流式接口；
2. `launchAttack` 检出公式 → 换服务端分类器（评测方案见开发文档 §9）；
3. `CAMPAIGN` 固定队列 → 换题库 API（"每日挑战"动态出题）。
4. `Auth` / `AdminData`（本机账号与题库）→ 换服务端鉴权与题库接口：前端只保留调用层，`AKEY()` 隔离的存档改为服务端记录。

## 六、测试记录（交接时的状态）

- 已做浏览器自动化全流程回归：四波分拣（含连击/血量/超时路径）、拆解台 10/10 证物归位、实验室拖卡 3/3+滑杆实时预测+投放噪声结算、自由撰写命中高亮、报告/雷达/画像、语音与追问。
- 修复过并需知晓的两个坑：拖拽元素若带 `transition: transform` 会丢快速拖放（已禁用并加 `.dragging`）；合成 PointerEvent 下 `setPointerCapture` 会抛错（已 try/catch，真实输入不受影响）。
- 兼容性：Chrome/Edge/Safari 现代版本；语音（Web Speech）在部分 Linux 浏览器不可用，会自动静默降级。
- 账号与控制台（本次新增）已做：42 项 auth 单元测试（含 SHA-256 与 Node 原生实现逐串比对、注册规则、改密/重置/删除保护）、无头浏览器端到端（登录页→注册登录→学员首页→管理员看板：折线图/环形图实际绘制像素校验、四个面板切换、题库与波次的错误数据拦截、账号表渲染）。
