# 识渔计划 SHIYU · Web 前端（v3 游戏版）

反钓鱼攻防训练 H5 游戏：**剧情模式**（五章分支叙事 + 终章）+ **拦截战**（10 次限时分拣）+ **拆解台**（结算后的可选证物复盘）+ **造浪者组装实验室**（拖卡调参/自由撰写）+ **反钓鱼知识库**（L0 首页 / L1 知识域 / L2 条目；22 个条目、搜索、知识树、学习路径、已读进度）+ **AI 蓝军安全官**（打字机点评、语音、追问）。纯静态实现，零后端、零外部依赖、离线可运行，进度存 localStorage。

## 快速启动

- **Windows**：双击项目根目录 `启动识渔计划.bat`
- **任意系统**：
  ```bash
  cd webapp
  python -m http.server 8765      # 或 npx serve / 任意静态服务器
  # 浏览器访问 http://127.0.0.1:8765（电脑 / 手机通用：应用区固定 9:16，居中并自动缩放至完整显示）
  ```
- **部署**：整目录上传任意静态托管（校园服务器 / GitHub Pages / 对象存储），入口 `index.html`，建议 HTTPS。

## 启动页

- 打开页面先显示 `#splash`，固定约 2 秒后淡出并移除；页面内无按钮、输入框或可点击元素，不要求任何操作。
- 进度线为纯 CSS 动画；`prefers-reduced-motion` 下关闭动画，但仍保留 2 秒停留。

## 玩法的独立边界

- **拦截战**与**造浪者**从首页卡片各自独立进入，彼此不自动串联；拦截战报告页只提供“再来一局”“拆解复盘（可选）”“返回首页”，不会中途插入拆解台。
- 两个玩法都在页头提供「退出」按钮；退出会停止本局计时/动画并回到玩法选择，当前这局进度不保留。
- 所有视图共用同一个 9:16 主舞台：页头/页脚固定，内容超出时只滚动内容区，不改变舞台比例。

## 反钓鱼知识库

- **入口**：首页卡片、报告页、关于页；顶部“返回”回到上一级，“退出知识库”回到进入前页面。
- **层级**：L0 首页（4 个知识域 / 搜索 / 3 条学习路径 / 最近更新）→ L1 知识域或子类（难度与标签筛选、子类分组、条目列表）→ L2 条目（TOC、定义、为什么危险、一眼识别、话术例、误区、关联、被引用、出处、已读）。
- **路由**：`#kb`、`#kb/domain/recognize`、`#kb/domain/attack/psych`、`#kb/entry/flag/domain_spoof`、`#kb/entry/gene/g1`、`#kb/entry/dim/domain`、`#kb/entry/response/stop-loss`、`#kb/path/quick`；支持直达、刷新、前进/后退，非法路由回退 `#kb` 并提示。
- **数据**：`data.js` 的 `CATEGORY_DOC` / `DIM_DOC` / `STOP_LOSS` / `ATLAS_SOURCES` / `GENES` 只保留一份正文；`KB_DOMAINS` / `KB_SUBDOMAINS` / `KB_PATHS` / `KB_ENTRIES` 做索引与适配，`kbFromFlag` / `kbFromGene` / `kbFromDim` / `kbFromStop` 负责组装条目。
- **检索与进度**：前端内存搜索（标题/摘要/标签/关键点），知识树抽屉，`shiyu_kb_read_v1` 记录已读与最近浏览；不采集个人信息。
- **适配**：360 / 420 / 620px 宽度无横向溢出；桌面端条目页为目录 + 正文双栏，移动端目录折叠。

## 核心模块速览

- `startGame()/nextCard()/sortCard()/exitGame()` —— 拦截战：每波 1 张、共 10 次发牌与限时，拖拽/键盘分拣、连击与血量结算、第 10 次后直接生成报告、主动退出
- `startDismantle()/startReviewDismantle()/bindChipDrag()/finishDismantle()` —— 拆解台：报告页可选复盘，证物生成、指针坐标命中槽位、首放命中/试错判定与讲解，复盘不计入正式战绩
- `renderAttack()/bindGeneDrag()/launchAttack()/launchFreeAttack()/exitAttack()` —— 实验室：拖卡装配（同类型卡可叠进同一个槽）、滑杆实时改预测仪（±误差）、投放噪声结算、扫描束动画、主动退出；自由撰写规则引擎（`FREE_RULES`）
- `labCardsFor()/labSelection()/labPredict()` —— 只接受“卡片类型 = 槽位类型”的合法装配；同槽多卡按检出分累加，缺组或错槽返回 `null`，避免预测仪取空值崩溃
- `Officer` —— 安全官：逐条打字机气泡 + Web Speech 语音 + 快捷追问（`OFFICER_QA`，本地知识库回答）
- `SFX` —— WebAudio 合成音效（拾取/命中/警报/连击），无音频文件
- `drawRadar()/finishGame()/renderReport()` —— 五维画像与前后测报告
- `renderKB()/kbParseHash()/kbSearch()/kbBuildTree()` —— 知识库：hash 路由、L0/L1/L2 渲染、前端搜索、知识树、已读进度
- `Story`（story-engine.js）—— 剧情模式：章节列表、事件渲染、选项判定、分支路由、章节结局、好结局数量判定与终章、`S.story` 断点续玩

## 剧情模式规则

- 顺序固定：`学费 → 学长 → 饰品 → 修电脑 → 代刷`。
- 每章按选择进入本章好/坏结局；选错次数会记录，但不阻止进入下一章。章节结束页的标题会直接标注「好结局」或「坏结局」，并用绿色 / 红色区分。
- **五章中好结局不超过 2 章** → 解锁终章「回血」，终章固定进入坏结局。
- **五章中好结局达到 3 章及以上** → 第五章结束后不进入终章，直接进入主线好结局。
- 已读章节可以点击重读。重读前会保存当前进度快照，读完后自动还原，不会覆盖本周目的章节记录与主线进度。
- 剧情进度随 `shiyu_v3` 存档，旧存档无 `story` 字段时自动初始化为新剧情。剧本选项支持 `next`（跳到指定事件）与 `ending: "good"|"bad"`（强制结局），未写时按 `correct` 与故事默认规则路由。

## 屏幕适配与故事分页

- **9:16 主舞台**：`#wrap` 的宽度取 `min(100vw, 100dvh × 9/16, 620px)`（旧浏览器回退 `100vh`），高度按 9:16 推导，`body` 使用 flex 上下左右居中；手机竖屏、桌面浏览器都完整显示，不裁切。页面头部/底部固定，中间 `#app` 作为各视图的独立滚动区。
- **固定高度故事框**：剧情简介、事件、选择结果、章节结局和最终结局统一进入 `.story-text` 阅读框；正文框由 flex 占据舞台剩余高度，尺寸不随文字多少变化。
- **自动分页**：`storyPaginate()` 用离屏测量容器按真实宽度/高度逐块累加，超出固定框就分页；长段落先按标点拆成小块。只有存在下一页时才启用「下一页」，并支持「上一页」回看。
- **两级正文样式**：普通旁白与 `systemState` 系统状态统一为正文排版，后者使用次要灰色文字；`messages` 邮件/聊天内容统一渲染为引用卡片，发件人只在卡片头部显示一次，跨页时在卡片头标注「续」。
- **选择延后出现**：事件选项与「继续」按钮只在该事件正文的最后一页显示；操作区初始即隐藏，分页测量完成后再决定是否显示，避免翻页时选项闪一下。未读完时操作区保留占位并提示“继续阅读至最后一页”，避免正文框高度跳动。
- **窗口变化**：监听 `resize` 重新测量分页；当前页码会保留并自动夹紧到有效范围。

## 数据结构（data.js）

样本 Schema（后端化时题库表结构同构）：

```jsonc
{
  "id": "em1", "carrier": "email|sms|linkpage", "difficulty": 1-3,
  "phishing": true, "scene": "场景名",
  "meta": { "from/addr/subj/time" | "phone/time" | "url/title" },
  "parts": [ { "t": "p|link|attach|qr|btn|field", "id": "靶点id", "text|html": "…" } ],
  "redflags": [ { "category": "7类之一", "target": "parts.id", "explain": "讲解文案" } ],
  "legitNotes": [ { "target": "…", "note": "正常样本的教学说明" } ]
}
```

## 如何扩展

- **加样本**：按 Schema 在 `SAMPLES` 追加，并把 id 编入 `CAMPAIGN` 的 10 次队列（前测 3 / 训练 4 / 后测 3）；靶点 id 必须与 `redflags.target` 一致（可跑根目录校验脚本核对）。
- **加检测规则**：`FREE_RULES` 追加 `{k, name, cls, det, re, know}` 即同时生效于自由撰写与复盘。
- **换/接大模型**：`Officer.play(script)` 的 script 与 `OFFICER_QA[*].a()` 是唯一话术出口——替换为后端流式接口即可，前端打字机与 TTS 复用；`launchAttack` 的检出公式可替换为服务端分类器。
- **音效/语音开关**：右上 `🔊`（localStorage `shiyu_voice`）。

## 合规要点（内建）

全部样本虚构（域名/人名/链接均为演示虚构，不产生真实跳转）；无发送能力；界面“教学模拟”水印；免登录匿名、数据仅存本地；高发骗术类型参考国家反诈中心公开宣传。参赛提交时按当届要求附《AI 工具使用说明》（模板见根目录申报书第七章）。
