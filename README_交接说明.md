# 识渔计划 · 项目交接说明

> 反钓鱼攻防训练 H5 游戏（参赛作品）
> 本文件是交接总入口：拿到包先读这里。

## 一、这是什么

一个纯前端 H5 游戏（零后端、零外部依赖、离线可运行），训练大学生识别钓鱼诈骗的能力：

| 模式 | 玩法 | 训练目标 |
|---|---|---|
| **启动页** | 进入时约 2 秒极简过场（Logo / 训练营 / 进度线），无按钮、无输入框，自动进入首页 | 品牌与进入仪式感 |
| **拦截战** | 每波 1 张、共 10 次限时分拣，拖进左侧渔网（钓鱼）或右侧收件箱（正常）；连击计分、数据完整度血条、超时漏网，第 10 次后直接结算 | 快速真假判断（行为训练） |
| **拆解台（可选复盘）** | 结算后可选：把本局钓鱼样本的证物（域名/链接/话术/附件碎片）拖进 7 类破绽槽位；首放命中/试错判定、放错弹回，不计入正式战绩 | 破绽定位与归类（知识内化） |
| **反钓鱼知识库** | L0 首页（4 个知识域 / 搜索 / 3 条学习路径 / 最近更新）→ L1 知识域（7 类破绽、9 张伪装卡、5 维能力、应急处置）→ L2 条目（定义 / 识别 / 话术例 / 误区 / 关联 / 出处）；顶部知识树与 hash 路由，已读进度存本地 | 知识结构化（赛前速查/赛后补课） |
| **造浪者·组装实验室** | 拖伪装卡（身份/心理/技术）入对应装配槽（同类型卡可叠进同一槽） + 三根滑杆调参（伪装度/激进度/投放量），预测仪带 ±8 误差，投放后邮件飞越扫描光束揭晓真实检出率；或**自由撰写**一封钓鱼邮件由规则引擎逐词高亮判检 | 攻击者视角反推防守 |
| **AI 蓝军安全官** | 全程打字机点评 + 浏览器语音播报 + 快捷追问 | 反馈与陪伴感 |
| **风险画像** | 前测→训练→后测，五维雷达图（域名甄别/话术免疫/链接警惕/附件谨慎/紧迫感抗压）+ 段位 + 个性化建议 | 效果量化（可写进论文/报告） |

## 二、怎么跑起来

1. **最快**：双击 `启动识渔计划.bat`（Windows，自动起本地服务并打开浏览器）。
2. **通用**：任意静态服务器指向 `webapp/` 目录，如 `python -m http.server 8765`，访问 `http://127.0.0.1:8765`。
3. **上线部署**：`webapp/` 整目录上传静态托管即可（建议 HTTPS）；无构建步骤、无环境要求。

> 注意：不要用 `file://` 直接双击 index.html（部分浏览器限制 localStorage/语音），走本地服务器即可。

## 四、代码导读（5 分钟上手）

- 入口 `index.html` → `app.js` 底部 `init()`；视图切换 `show()`。
- **数据与逻辑完全分离**：加题/改题只动 `data.js`，不碰逻辑；样本 Schema 与扩展方法见 `webapp/README.md`。
- **反钓鱼知识库**：`data.js` 的 `CATEGORY_DOC` / `DIM_DOC` / `STOP_LOSS` / `ATLAS_SOURCES` / `GENES`，加上 `KB_DOMAINS` / `KB_SUBDOMAINS` / `KB_PATHS` / `KB_ENTRIES` 索引适配层；`app.js` 的 `renderKB()` 与 hash 路由；不复制正文，改一处全库同步。
- 交互核心都是**指针事件拖拽**（拦截卡/证物/伪装卡三套 bind 函数），命中判定用"指针坐标落在槽内"（`slotAtPoint`），新增拖拽物复用该模式即可。
- 音效 `SFX`（WebAudio 合成）、语音 `Officer.tts`（Web Speech）——全部本地能力，无任何 API Key。

## 六、测试记录（交接时的状态）

- 已做浏览器自动化回归：覆盖十次选择编排（每波 1 张、10 张不重不漏）、第 10 次后直接结算、前后测按样本集合聚合、报告页可选拆解复盘、实验室悬停/拖卡/错槽/同槽叠卡/点击移出/装配后移除且不拦截指针；此前的全流程回归仍覆盖连击/血量/超时、拆解归位、投放噪声、自由撰写、报告/雷达/画像、语音与追问。
- 修复过并需知晓的两个坑：拖拽元素若带 `transition: transform` 会丢快速拖放（已禁用并加 `.dragging`）；合成 PointerEvent 下 `setPointerCapture` 会抛错（已 try/catch，真实输入不受影响）。
- 本轮修复：拖拽处理器增加 `pointerdown` 门控与 `pointerId` 校验，鼠标仅悬停不再触发 `translate`（造浪者卡片 / 拆解台证物均已覆盖）；拦截战改为每波 1 张、共 10 次选择（前测 3 + 训练 4 + 后测 3），第 10 次后直接结算，不再中途跳拆解台；拆解台改为报告页的可选复盘。造浪者支持同类型多卡叠进同一槽、按检出分累加，槽内卡片可点击移回牌堆；装配成功后卡片从牌堆移除。拖拽中的卡片不再设置 `pointer-events:none`，改由显式 `releasePointerCapture` + document 级 `pointermove`/`pointerup` 兜底，避免遮挡其他卡片的命中区。
- 兼容性：Chrome/Edge/Safari 现代版本；语音（Web Speech）在部分 Linux 浏览器不可用，会自动静默降级。
